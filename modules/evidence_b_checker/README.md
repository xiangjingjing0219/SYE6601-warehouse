# 证据链 B：故障补偿证据检查器

检查合同、故障记录和工单能否支撑补偿判断。每项检查保留原文位置、证据编号和审核结果：支持、反驳、未知或冲突。补到新材料后重新判断，并保留之前的结果。

例如，某份客户合同要求在故障发生后 24 小时内提交工单。查到合同只能确认有这项要求；还没查到工单时，“是否按时提交”仍是未知。取得适用工单后，才比较故障时间和提交时间。

## 如何运行

用 Colab 打开 [岗位验收演示.ipynb](岗位验收演示.ipynb)，按顺序运行。演示使用 CPU，离线回放已保存的模型记录，不需要 API 密钥。

## 联调与验证结果

| 检查内容 | 结果 |
| --- | --- |
| 故障补偿联调案例 | 63 个合成案例和 7 个边界案例，共 70 个，均符合预期 |
| 原检查器回归测试 | 39 项通过 |

边界案例覆盖错客户、错事故、记录过期、缺少版本、同一工单编号内容冲突、提交时间晚于查询时间，以及截止前查到空结果。上述数字是开发验证结果，不代表实际业务准确率。
